# Product card images

Each homepage product card shows `<product-id>.jpg` from this folder
(jpg, jpeg, png or webp are all picked up automatically):

- `jamjoom-online.jpg`
- `eotra-menu.jpg`
- `neoshe.jpg`
- `ibosh.jpg`
- `lidya.jpg`
- `tradespilot.jpg`

The current files are real screenshots of each live site (captured Nov 2026),
placed as a window on the card's brand-colored background (1200 x 1500, 4:5).
To refresh or replace one, overwrite the file with the same name. The logo is
drawn on top of the image, top-center, so keep the top ~200px of any
replacement image clean.
